## 1. エレベーターピッチ

**Footics** は、プレミアリーグを中心としたフットボール戦術分析コンテンツ（YouTube / X 等）の制作を支援する、**個人用オールインワンプラットフォーム**です。

- 試合データの収集・閲覧からはじまり、戦術ボードの作成、スクリーンショット撮影・編集、最終的なコンテンツ書き出しまでを**一つのアプリで完結**させることを目的とする
- 個人の制作ワークフローに最適化されており、一般公開・マルチユーザー対応は**スコープ外**
- データはすべて**ローカル（IndexedDB）に保存**。サーバーへの送信は行わない
- アプリ本体は Cloudflare Workers にデプロイされ、ブラウザ上で動作する

## 2. 主要ドメイン概念

### 2-1. 試合データ系

| エンティティ | 説明 |
|------------|------|
| `Match` | 試合の基本情報（対戦チーム・日付・スコア・大会）。クラブ戦と代表戦の2系統 |
| `Team` | チーム情報。チェルシーを中心に扱うが全クラブ対応 |
| `Player` | 選手情報（名前・ポジション・背番号）。WhoScored データから取得 |
| `MatchEvent` | 試合内のイベント（ゴール・カード・交代・チャンス創出等） |
| `EventMemo` | 各イベントに紐づく分析メモ（テキスト） |
| `MatchMemo` | 試合全体に対するメモ |

**データ取得フロー:**
```
WhoScored サイト
  → 自作 Chrome 拡張（Footics とは別の拡張機能）でスクレイプ
  → JSON ファイルとしてダウンロード
  → Footics の Import 機能で取り込み → Dexie.js (IndexedDB) に保存
```

### 2-2. 戦術ボード系

| エンティティ | 説明 |
|------------|------|
| `TacticalProject` | 戦術ボードの1プロジェクト（スライド群 + アスペクト比設定） |
| `TacticalPlayer` | ボード上の選手オブジェクト（位置・番号・チームカラー） |
| `ArrowAnnotation` | 動きを示す矢印オブジェクト |
| `ZoneAnnotation` | ゾーン・エリアを示すオブジェクト |
| `TextAnnotation` | テキストラベルオブジェクト |
| `BallState` | ボールの位置オブジェクト |

**対応アスペクト比:** 16:9 / 9:16 / 4:5 / 1:1

**エクスポート形式:** PNG / MP4 / WebM / GIF（WebCodecs API + mp4-muxer / webm-muxer / gif.js）

### 2-3. スクリーンショット系

| エンティティ | 説明 |
|------------|------|
| `Screenshot` (仮) | Footics 統合拡張機能でキャプチャした画像 |

**現在のフロー（部分的にバグあり）:**
```
ユーザーが YouTube 等でビデオ視聴中
  → Alt+S でキャプチャ（Footics 統合 Chrome 拡張）
  → BroadcastChannel 経由で Footics に転送
  → Footics タブが開き、戦術ボード編集画面に遷移
  → [未解決] スクリーンショットが戦術ボードの背景に設定されない
```

## 5. ディレクトリ構成（概要）

```
footics/
├── src/                    # Next.js アプリ本体
│   ├── app/                # App Router（ページ定義）
│   │   ├── /               # 試合一覧 + JSON インポート
│   │   ├── match/[matchId] # イベントタイムライン分析
│   │   ├── tactical/       # 戦術ボードエディタ（メイン）
│   │   └── teams/[teamId]  # 選手マスターデータ
│   ├── components/         # UI コンポーネント
│   │   └── features/       # 機能単位のコンポーネント群
│   ├── stores/             # Zustand ストア（スライス）
│   └── types/              # 型定義
├── extension/              # Footics 統合 Chrome 拡張（WXT）
├── tasks/                  # エージェント用タスクファイル格納先
├── tests/                  # 統合テスト・評価ベンチマーク
└── docs/                   # 仕様・ドメイン知識リファレンス（辞書）
```
