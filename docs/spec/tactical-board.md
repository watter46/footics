# 戦術ボード (Tactical Board)

## 概要
フットボールの戦術図や連続的なフォーメーションの動きを作成・編集するためのメインキャンバス画面（`/tactical`）です。
ピッチ上に選手マーカー、矢印、ゾーン、テキストを自由に配置できるほか、複数のシーン（スライド）をパラパラ漫画のようにつなげて滑らかなアニメーション動画を作成できます。

---

## できること (DO)

### ユーザーの主な操作

#### 1. プロジェクト管理
- **新規プロジェクト作成**:
  - 画面上部のメニューから「新規プロジェクト」を選択、またはプロジェクト管理画面からアスペクト比、初期背景（ピッチ/無地）、チームカラー（ホーム/アウェイ）を指定して作成できます。
- **プロジェクトの切り替え・一覧表示**:
  - 保存済みの戦術プロジェクト一覧をカード表示（グリッド）またはリスト表示で閲覧し、クリックで瞬時に切り替えることができます。
- **プロジェクトの複製・削除**:
  - プロジェクトをワンクリックで完全複製できます。
  - 不要になったプロジェクトは個別に削除（確認ダイアログあり）、または複数選択して一括削除できます。
- **タイトルの変更**:
  - 画面最上部のプロジェクト名をクリックして、その場で直接名前を編集できます。
- **プロジェクトファイルの書き出し・読み込み**:
  - 単一プロジェクトをJSONファイルとして書き出したり、複数プロジェクトをZIPファイルにまとめて書き出したりできます。外部のJSONファイルを読み込んでプロジェクトを復元することも可能です。

#### 2. シーン（スライド）管理
- **シーンの追加**:
  - 画面下部のタイムラインバーにある「シーン追加」ボタンを押します。
  - **左クリック**: オブジェクトが何も乗っていない空の新規シーンを追加します。
  - **右クリック**: 現在編集中のシーン（選手の配置や矢印など）を完全に引き継いだ複製シーンを追加します。
- **シーンの複製・削除**:
  - 各シーンのカード上に表示されるアイコン、または右クリックメニューから複製や削除が行えます。
  - ※プロジェクト内に最低1枚のシーンが必要なため、最後の1枚は削除ボタンが無効化されます。
- **シーンの並び替え**:
  - タイムライン上のシーンカードをドラッグ＆ドロップして左右の順序を直感的に入れ替えられます。
- **アニメーション速度と待機時間の設定**:
  - 画面右側のパネルから、前のシーンから現在のシーンへ選手が移動する時間（0.2秒〜5.0秒）や、移動完了後に静止する時間（0秒〜3.0秒）、動きの加減速（スムーズ、一定速度など4種類）をスライダーで細かく調整できます。

#### 3. キャンバス上の作図操作
- **右上の常駐ツールバー**:
  - 選択ツール、直線、移動ルート線、実線矢印、破線矢印、波線矢印、矩形ゾーン、多角形ゾーン、テキストラベル、2D選手マーカー、3D足元リング選手マーカーを切り替えて配置できます。
  - **連続配置ロック**: 有効にすると、1つ配置した後もツールが選択状態のまま維持され、連続して同じオブジェクトをピッチ上に配置できます。
  - **消しゴム**: ピッチ上のオブジェクトをクリックして消去できます。
- **選手マーカーの操作**:
  - マウスでドラッグして自由にピッチ上を移動できます。
  - 選手を選択すると、右パネルから背番号、選手名、所属（ホーム/アウェイ）、視野コーン（見ている方向と広さ・色）、他選手との連携ライン、スポットライト強調などを設定できます。
  - ベンチ（サブ選手）枠からピッチ上へドラッグ＆ドロップして選手を投入することも可能です。
- **矢印・ライン**:
  - 選手の足元から別の場所へ矢印を伸ばせます（選手を動かすと矢印も自動追従します）。曲線の曲がり具合も自由に調整可能です。
- **ゾーン（エリアの強調）**:
  - 四角形や多角形（頂点をクリックして囲む形状）を配置し、色や透明度を変えてスペースやプレッシングエリアを可視化できます。
- **テキスト**:
  - 任意の場所をダブルクリックして、解説テキストをピッチ上に直接入力できます。
- **元に戻す (Undo) / やり直し (Redo)**:
  - 画面上部のボタン、またはショートカットキー（`Ctrl + Z` / `Ctrl + Shift + Z`）で直前の操作を取り消したり再適用したりできます。

#### 4. 表示設定とアスペクト比
- **アスペクト比の切り替え**:
  - 画面上部のボタンで `16:9`（YouTube/PC俯瞰用）、`9:16`（スマホ縦画面・リール用）、`4:5`（SNSタイムライン最大表示用）、`1:1`（正方形）を切り替えられます。
- **背景の変更**:
  - サッカーピッチ、無地（白/黒背景）、画像背景を切り替えられます。
  - 画像ファイルを手動で選択して読み込めるほか、画像をピッチ上にドラッグ＆ドロップしたり、クリップボードの画像を貼り付け（`Ctrl + V`）たりするだけで即座に背景画像として設定できます。
- **陣地の反転**:
  - メニューから「陣地反転」を選ぶと、ピッチ全体の左右（横画面時）または上下（縦画面時）が瞬時に逆転します。

#### 5. アニメーションのプレビュー再生
- **再生 / 一時停止**:
  - 下部バーの再生ボタン、またはキーボードの **スペースキー** で、第1シーンから最終シーンまでの動きをリアルタイム再生できます。
  - 選手やボールが設定した秒数と加減速に合わせて滑らかに移動します。

### 入力制限・保存トリガー
- **自動保存**: ピッチ上でオブジェクトを動かしたり設定を変更したりすると、操作を止めてから約0.8秒後に自動的にブラウザ内に保存されます。上部バーの表示が「保存中...」から「保存済み」に変わります。
- **離脱時の一括保存**: ブラウザタブを閉じたり別の画面へ移動したりする際も、未保存の変更が即座に自動保存されます。

## やってはいけないこと (DON'T / スコープ外)

- **オフライン外へのクラウド同期**: 作成したプロジェクトはブラウザ内にのみ保存され、別端末のブラウザへ自動同期されることはありません。
- **手動保存ボタンの押下**: 常に自動保存が作動するため、「保存」ボタンを押す必要はありません（明示的な手動保存ボタン自体が存在しません）。
- **ボール専用の新規追加ツール**: ツールバー上には選手や矢印の配置ボタンはありますが、「新規ボール配置」ボタンはありません（シーン内に初期配置されているボールを移動させて作図します）。
- **外部動画の直接取り込み再生**: キャンバス上で動画ファイルを直接再生しながらその上に上書き作図する機能はありません（動画から切り出した静止画を背景に設定して作図する形となります）。

## 画面遷移・状態変化

- **他画面からの遷移**:
  - トップ画面や試合詳細画面から遷移してきた場合、直前まで編集していたプロジェクト、または該当試合の配置が自動で読み込まれます。
- **アスペクト比変更時の自動配置変換**:
  - 横画面（16:9）から縦画面（9:16など）に切り替えた場合、ピッチの向きに合わせてすべての選手や矢印の位置が自動的に90度回転して再配置されます（元の横向きの見た目とは縦横の座標関係が変化します）。
- **フィードバック通知**:
  - プロジェクトの作成、複製、削除、タイトルの変更が成功した際、画面の隅に通知メッセージ（トースト）が表示されます。

---

## エラー・例外時の挙動

- **シーン削除時の確認ダイアログの差異**:
  - 画面下部のタイムラインバー上でシーンをごみ箱アイコンから削除した場合は、確認ダイアログが出ずに**即座に削除**されます。
  - 画面右側のパネルから「シーンを削除」ボタンを押した場合は、ブラウザの確認ダイアログ（「このスライドを削除してもよろしいですか？」）が表示されます。
- **保存エラー**:
  - ブラウザの容量不足などで自動保存に失敗した場合、上部バーのステータスが赤色の「保存失敗」に変化します。
- **プロジェクト全削除時の保護**:
  - プロジェクトをすべて削除して0件になった場合、自動的に空の新規プロジェクトが1件生成され、画面が白紙クラッシュすることを防止します。
