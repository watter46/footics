# 試合分析・イベントタイムライン (Match Analysis)

## 概要
インポートした特定の試合（`/match/[試合ID]`）について、試合開始から終了までの全プレーイベント（パス、シュート、ファウル、タックル等）を時系列のタイムラインとして閲覧し、詳細な絞り込みや独自の戦術分析メモ・独自イベントを記録するための画面です。クラブ戦と代表戦で専用の画面構成が用意されています。

---

## できること (DO)

### ユーザーの主な操作
- **タイムラインの閲覧**:
  - 試合中の全イベントを縦スクロールで滑らかに一覧表示します。
  - 表示項目: 発生時刻（分:秒）、選手名（所属チーム別の色付きバッジ）、所属チーム、イベント種別（シュート、ゴール、パス等）、成功/失敗インジケータ、戦術ルール合致バッジ。
  - **並び順の反転**: 画面上部の切り替えボタンにより、「前半開始から（昇順）」と「試合終了から過去へ遡る順（降順・初期表示）」をワンクリックで切り替えられます。
- **イベントの多角的な絞り込み（サイドバー）**:
  - チーム選択（ホーム / アウェイ / 全体）
  - 選手選択（一覧から特定の選手を複数選択、または一括解除）
  - プレーの成否（すべて / 成功のみ / 失敗のみ）
  - 戦術的関心事（特定の攻撃パターンやビルドアップ条件）の合致有無
  - タイムライン種別（全イベント / 独自追加イベントのみ等）
- **戦術ボードとの時間連携（別タブ起動）とフォーメーション自動マッチング**:
  - 各イベント行の右端にある「外部リンクアイコン」をクリックすると、新しいブラウザタブで戦術ボード画面（`/tactical?matchId=...&minute=分`）が自動的に開き、その時間帯のピッチ状況を作図・確認できます（本画面内にはピッチ描画領域はありません）。
  - **スタメン11人・控え・交代退場選手の高精度自動抽出（クラブ戦）**:
    - 指定分数における WhoScored の出場スロット情報（`formationSlots`: `1〜11` がピッチ上、`0` が未出場控え）と相対縦横スロット座標（`formationPositions`）に基づき、該当時間帯に出場している選手11人を正確にピッチ上へ抽出します。
    - ベンチ控え選手には、未出場の控え選手（スロット0）を先頭に、すでに交代でベンチへ退いた先発選手をその後ろに並べて展開し、交代前後の戦術シーン作成をスムーズに行えます。
  - **ポジション適性マッチングによる自動配置**:
    - WhoScored の特殊なフォーメーション名（`41212` ➔ `4-3-1-2`、`31312` ➔ `3-4-1-2`、`343d` ➔ `3-4-3`、`4240` ➔ `4-2-4` 等）や、ウイングバック・ウイング（`DML, DMR, FWL, FWR` 等）を含む全ポジションを正規化します。
    - フォーメーション枠の縦ライン（GK・守備・中盤・前線）および左右レーン（左・中央・右）の適性を判定するマッチングアルゴリズムにより、各選手のポジションやスロット位置に合致する枠へ正確に自動配置されます（例: 右SBが右サイド枠、左CBが左側CB枠へ）。
    - 途中交代出場により元のデータ上のポジションが `'Sub'` となっている選手には、割り当てられたフォーメーション枠のポジション（CB, LB, RB, CM, WG 等）が戦術ボード上で自動補完されます。
  - **戦術ボード Formation パネルとの連動**:
    - 戦術ボード側で該当試合のフォーメーションが保持され、右パネルの Formation タブを開いた際、選択中チーム（Home / Away）の試合フォーメーションがプリセット一覧上で自動的にアクティブ表示されます。
    - 試合連携状態の戦術ボードで「New Project」を実行した場合も、汎用ボードには戻らず、当該試合の出場・控えメンバーとフォーメーションを引き継いだ新規プロジェクトとして初期化されます。
- **試合全体メモ（Match Memo）の閲覧・編集**:
  - タイムライン最上部に配置されたメモカードをクリック、または鉛筆アイコンをクリックして入力モーダルを開き、試合全体に対する戦術総括や所感をテキスト入力できます。
- **独自イベント（Custom Event）の手動追加・編集・削除**:
  - **追加**: ヘッダーの「イベント追加」ボタンを押すと、3段階の案内画面（ステップ0: 時間・前後半の指定 → ステップ1: イベント種別ラベルの選択 → ステップ2: メモ記述）が表示され、公式データにない独自の着眼点をタイムラインに挿入できます。
  - **編集**: 追加した独自イベント行の鉛筆アイコンを押すと、即座にメモ編集画面が開きます（前へ戻るボタンで時間やラベルの変更も可能）。
  - **削除**: 独自イベント行のゴミ箱アイコンを押すと、確認ダイアログの後にタイムラインから削除されます。
- **個別試合データの入出力（クラブ戦のみ）**:
  - 上部メニュー「データ」から、当該試合の分析メモのみをJSONファイルとして書き出したり、外部からメモJSONを取り込んで上書き・統合したりできます。

### 入力制限・保存トリガー
- **時間指定**: `分:秒` の正しい数値形式のみ受け付けます。
- **保存トリガー**:
  - 入力画面（モーダル）内の「保存」ボタンをクリックする。
  - キーボードの `Ctrl + Enter` または `Cmd + Enter` を押す。
  - ※保存処理中はボタンが無効化され、二重送信が防止されます。
- **キャンセルトリガー**:
  - モーダル右上の「×」ボタン、または下部の「キャンセル」ボタンをクリックする。
  - モーダル外側の暗い背景をクリックする、または `Escape` キーを押す。

## やってはいけないこと (DON'T / スコープ外)

- **画面内でのピッチ図直接表示・編集**: この画面の中にミニピッチを表示して選手の位置を直接動かす機能はありません。ピッチ上の配置を見たり動かしたりしたい場合は、必ずイベント行から別タブの戦術ボードを呼び出す必要があります。
- **公式イベントの直接書き換え・削除**: 外部データから取り込んだ公式のプレーデータ（選手名、発生時刻、シュートの成否など）そのものをタイムライン上で改ざんしたり、行を削除したりすることはできません（編集・削除できるのは自分が追加した独自イベントやメモのみです）。
- **代表戦画面でのメモ・独自イベント管理**: 代表戦の試合詳細画面では、現状タイムラインの閲覧と戦術ボードへの遷移のみが提供されており、試合全体メモの編集や独自イベントの追加、メモJSONの入出力機能は省かれています。

## 画面遷移・状態変化

- **戦術ボードへの遷移**: イベント行のアイコンをクリックすると、現在の分析画面を維持したまま、別タブで該当時間の戦術ボードが立ち上がります。
- **保存成功時のフィードバック**:
  - メモや独自イベントを保存した際、画面上に「保存しました」といった通知（トースト）は表示されません。
  - 入力画面（モーダル）が静かに閉じ、タイムラインやメモカードの表示内容が自動的に最新の内容に更新されます。
- **キャンセル時のフィードバック**:
  - 入力画面を閉じると、保存前の入力内容は一切保存されずに破棄されます（事前の破棄警告ダイアログは出ません）。
- **一覧画面への復帰**: 画面左上の戻るボタンやパンくずリストをクリックすると、試合一覧画面（`/`）へ戻ります。

## エラー・例外時の挙動

- **試合データが存在しない場合**:
  - 指定された試合IDのデータが端末のローカルストレージに見当たらない場合、画面全体が赤枠の警告画面（`Data Not Found`）に切り替わります。
  - 画面上には「ローカルストレージに対象の試合データが見つかりません。先にJSONファイルをインポートしてください」という旨の案内と、「試合一覧へ戻る」ボタンが表示されます。
- **キャッシュデータの破損（復旧案内）**:
  - 試合の内部キャッシュが欠落している場合、画面全体が「キャッシュ復元画面」に切り替わり、試合データの再インポートが求められます。
- **保存失敗時の挙動**:
  - メモや独自イベントの保存中に何らかの不具合が発生した場合、画面上にエラー通知や警告は表示されず、入力画面が開いたまま保存ボタンの処理中表示が解除されます（ユーザー視点ではボタンを押しても反応しなかったように見えます）。
- **イベント削除時の確認**:
  - 独自イベントを削除する際のみ、ブラウザ標準の確認ダイアログ（「このイベントを削除してもよろしいですか？」）が画面上部にポップアップ表示され、「OK」を押すと即座に削除されます。
