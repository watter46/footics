# エクスポート・共有機能 (Export & Sharing)

## 概要
戦術ボードで作成した戦術図（静止画）や連続シーンのアニメーション（動画）を、各種SNS（X、YouTube、Instagramなど）や外部の動画編集ソフト（Premiere、Final Cut、DaVinci Resolve等）に最適な形式と解像度でローカル端末に書き出すための機能です。また、iPhoneやモバイル端末へワイヤレスで転送・保存するための専用共有機能も備えています。

---

## できること (DO)

### ユーザーの主な操作

#### 1. エクスポートモーダルの呼び出し
- 戦術ボード画面の右上にある「Export」ボタンをクリックすると、書き出し設定画面（モーダル）が開きます。
- モーダルは **「動画」「画像」「JSON」** の3タブ構成となっており、左側にリアルタイムのループプレビューと境界線枠（BoundaryBox）切り抜き状態が表示されます。
- また、トップバーにはワンクリックで現在のスライドを画像としてクリップボードへ保存できる「Copy PNG」ボタンも常設されています。

#### 2. 静止画（画像）の書き出し（「画像」タブ）
- **単一シーンのPNG書き出し**: 現在選択中のシーンを高画質なPNG画像（Konva `stage.toBlob()`）として保存します。
  - 解像度倍率を選択可能（1倍: 720p、2倍: 1080p フルHD、4倍: 4K 超高解像度）。
  - 各アスペクト比の基準解像度（`PITCH_BOUNDARY_CONFIGS`: 4:5なら 1080×1350、9:16なら 1080×1920、1:1なら 1080×1080、16:9なら 1920×1080）に基づき、アスペクト比の歪みや引き伸ばしなく描画されます。
  - 常に内部で保持されている境界線枠（BoundaryBox）の範囲が、選択されたフィット対象（ピッチフィット / 全画面フィット）に応じて純粋描画（Clean Render）で自動クロップされて書き出されます。
  - 選手マーカーが `Photo` モードの場合は、登録された顔写真（WebP）が円内にクリップ描画されて出力されます（未登録時は背番号にフォールバック）。
- **全シーンのZIP一括書き出し**:
  - プロジェクト内の全シーンを高解像度PNG画像として一度に連番生成し、1つのZIPアーカイブファイル（`fflate` 使用）にまとめてダウンロードできます。

#### 3. iPhone・モバイル連携高画質動画出力（「動画」タブ ＆ PWA 共有機能）
PCブラウザでの高負荷レンダリングを回避し、iPhoneの専用ハードウェア（A14 Bionic以降のメディアエンジン）を活用して高品位なMP4アニメーション動画を生成・保存します。
- **PC側からのワンクリック送信**:
  - 「iPhoneに送信してMP4を生成」ボタンを押すと、プロジェクトデータ（全シーン、アスペクト比、境界線枠、3Dカメラ傾き情報、大理石テクスチャ設定、および `Photo` モード選手の顔写真WebPバンドル）が一時共有ストアへ自動登録され、QRコードおよび共有リンクが発行されます。
- **iPhone専用 PWA 画面（`/export` ➔ `/export/share/[shareId]`）**:
  - ホーム画面に追加した PWA（`manifest.ts`、`start_url: '/export'`、`display: 'standalone'`、Apple Touch Icon 対応）または Safari で `/export` を開くと、送信済みプロジェクト一覧（最新順最大50件、タイトル、シーン数、アスペクト比バッジ、削除ボタン付き）が表示されます。
  - プロジェクトを選択して詳細画面（`/export/share/[shareId]`）へ進むと、ループ再生プレビュー（`ExportPreviewPlayer`）を確認できます。
  - **2大ビットレート比較プリセット**:
    - **`24mbps`** (1080p FHD, 60fps, 24Mbps, GOP 2秒, AVC/H.264): 最高画質アーカイブ・高精細配信用。
    - **`14mbps`** (1080p FHD, 60fps, 14Mbps, GOP 1秒, AVC/H.264): 容量を抑えつつ高画質を維持するモバイル最適化用。
  - **高速レンダリングパイプライン**:
    - Off-Thread Web Worker（`video-mediabunny.worker.ts`）によるバックグラウンド並行エンコード（Directメインスレッドへの自動フォールバック完備）。
    - 静止区間（`pauseMs`）での Canvas 再描画スキップにより、不要な描画負荷を完全に排除。
    - 統一フォント（`Geist`）、3D投影マトリクス（`mvpMatrix`）、大理石背景テクスチャ、選手顔写真が完全再現され、PCプレビューと100%同一の描画結果が得られます。
- **無劣化保存と Web Share API**:
  - iOSの写真アプリによる強制的な再圧縮劣化を防ぐため、直接ファイルダウンロードおよび Web Share API（`navigator.share({ files })` による「ファイルに保存」や AirDrop）による無劣化保存が提供されます。

#### 4. プロジェクトJSON入出力（「JSON」タブ）
- **Download JSON**: 現在の戦術プロジェクトデータ（全フェーズ・スライド・矢印・ゾーン・ピッチ外観等）を `.json` ファイルとしてローカルへ書き出します。
- **Copy to Clipboard**: プロジェクト全体のJSONテキストをクリップボードへコピーします。
- **Select Footics JSON File to Load**: 保存済みの Footics プロジェクトJSONファイルを選択して即座に復元・展開します。Zod によるスキーマサニタイズと耐障害性チェックが行われ、古い形式や微細な欠損があっても安全に補正して読み込みます。

### 入力制限・保存トリガー
- **実行トリガー**: 設定モーダル内の「書き出し開始」ボタンを押すと、バックグラウンド処理でレンダリングが始まります。
- **ダウンロードトリガー**: レンダリングが完了すると、自動的にブラウザのダウンロード処理が発動し、指定した形式のファイルが保存されます。

---

## やってはいけないこと (DON'T / スコープ外)

- **SNSへの自動直接アップロード**: エクスポートボタンを押しても、X（旧Twitter）やYouTubeへ直接ログインして動画を代理投稿する機能はありません。必ず一度端末にダウンロード保存した上で、ユーザー自身が各サービスの画面から投稿する必要があります。
- **音声・BGM・効果音の追加**: 出力される動画は映像（ビジュアル）のみであり、BGMや解説音声、効果音をアプリ内で付加して同時出力することはできません。
- **永久共有リンクの作成**: 発行・登録されるモバイル用プロジェクトデータは一時的なもの（24時間有効）です。外部の不特定多数に恒久的に公開するWebビューアとしての用途には対応していません。

---

## 画面遷移・状態変化

- **書き出し中の状態**:
  - 動画の書き出し中は、モーダル上に進捗バー（○%完了）と現在の処理シーン番号が表示されます。
  - 処理中もブラウザの描画や別作業が重くならず、スムーズに進行します。
  - 誤操作で画面が閉じて処理が中断されないよう、書き出し実行中は画面外クリックによるモーダル閉じが無効化されます。
- **処理のキャンセル**:
  - レンダリングの途中で「キャンセル」ボタンを押すと、いつでも書き出し処理を中断して安全に元の画面に戻れます。
- **完了時の通知**:
  - ファイルの保存が完了すると、画面に「エクスポートが完了しました」という通知が表示されます。

---

## エラー・例外時の挙動

- **動画書き出し機能に非対応の環境**:
  - お使いのブラウザが最新の高速動画エンコードに対応していない場合、自動的に標準的なブラウザ録画方式へ切り替わって書き出しが継続されます。
- **処理の失敗**:
  - メモリ不足や動画の結合処理に失敗した場合、モーダル上部に赤色の警告バーが表示され、失敗の理由が提示されます。
- **モバイル共有リンクの期限切れ**:
  - 発行から24時間以上経過した共有リンクや、存在しない共有IDにアクセスした場合、「共有リンクが見つからないか、有効期限が切れています」という専用エラー画面が表示され、アプリのトップへ戻るボタンが案内されます。
