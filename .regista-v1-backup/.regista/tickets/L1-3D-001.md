### 2. `matrix-coordinates.ts` の実装（新規ファイル）
ファイルパス: `src/features/tactical-unified/objects/canvas/helpers/matrix-coordinates.ts`

以下の純粋関数を実装すること（すべてgl-matrixの `mat4`, `vec3`, `vec4` を使用）：

#### 型定義
```ts
export type CameraParams = {
  tilt: number;      // チルト角度（度数法, 例: 0〜60）
  zoom: number;      // ズーム倍率（例: 1.0 = 100%）
  panX: number;      // パン X（ピッチ正規化座標系、-1〜1）
  panY: number;      // パン Y（ピッチ正規化座標系、-1〜1）
  stageWidth: number;
  stageHeight: number;
  fov?: number;      // 視野角（度数法, デフォルト 60）
};

export type ProjectedPoint = { x: number; y: number };  // 画面座標（px）
export type NormPoint = { x: number; y: number };         // ピッチ正規化座標（0〜1）
```

#### 関数群
```ts
/** MVP行列を生成する（Model=ピッチ平面, View=カメラ, Projection=透視投影） */
export function buildMVPMatrix(params: CameraParams): mat4

/** ピッチ正規化座標（normX, normY）→ 画面座標（px） */
export function projectPitchToScreen(norm: NormPoint, params: CameraParams): ProjectedPoint

/** 画面座標（px）→ ピッチ正規化座標（Raycasting / Unproject） */
export function unprojectScreenToPitch(screen: ProjectedPoint, params: CameraParams): NormPoint | null
// ピッチ平面（z=0）との交点を求める。ピッチ外はnullを返す。
```

#### 実装方針
- `buildMVPMatrix`: `mat4.perspective` + `mat4.lookAt` + `mat4.rotateX(tilt)` + `mat4.translate(pan)` + `mat4.scale(zoom)` の組み合わせ
- `projectPitchToScreen`: `vec4` にnorm座標を入れてMVP行列を乗算し、NDC→画面変換
- `unprojectScreenToPitch`: 逆行列 `mat4.invert` を用いてNDC逆変換→レイ方向計算→z=0平面との交点（パラメトリック直線交点）
