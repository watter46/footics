# 🟡 L2-DB-001: クエリ関数およびエクスポート機能へのスキーマ変更追従

## UX Impact
拡張機能とのデータ連携やエクスポート時に新しいデータフィールドが正しく保存・抽出されるようになります。

## Detailed Spec
1. `src/lib/db/queries.ts` および `src/lib/db/extension-db-queries.ts` にて、新スキーマに対応するINSERT/UPDATE/SELECT処理を修正する。
2. `src/lib/db/export.ts` でのエクスポート処理に新しいカラムや変更された型が含まれるよう対応する。
3. いずれもDBの基本CRUD操作に関わるため、純粋関数として副作用のない形を維持する。

## Acceptance Criteria & Verification Commands
- [ ] queries, extension-db-queries, export の各ファイルで型の不整合がないこと
- [ ] 既存のDB処理テストがあればパスすること

### Verification
`rtk biome check src/lib/db/`
`rtk pnpm type-check:scoped src/lib/db/queries.ts src/lib/db/extension-db-queries.ts src/lib/db/export.ts`
