# 🟢 L1-CLI-004: AGENTS規約とGMスキルのhandoverパス統一およびretry指示改善

## UX Impact
引継ぎドキュメントの保存先が単一ディレクトリ（`.regista/handover/`）に統一され、迷子ファイルがなくなるとともに、retry時に古いScoutキャッシュに囚われる問題が解消されます。

## Detailed Spec
1. `AGENTS.md` および `.agents/skills/regista-gm/SKILL.md` における引継ぎ文書の保存パスを `.regista/handover/{ID}-handover.md`（または `[ID]-handover.md`）に統一する（`.regista/handoffs/` や `[ID]-handoff.md` の表記を修正）。
2. `.agents/skills/regista-gm/SKILL.md` の「### 11. `retry {ID}` 自律リカバリプロトコル」における Scout 発行フォーマットに `"bypass_cache": true` を追加し、同一 git-hash でキャッシュが再利用されて不足情報が取得できなくなるデッドロックを防止する。
3. `AGENTS.md` の「### Worker Write-back プロトコル (MANDATORY)」に、`make done` 時に Write-back と `git status` の実差分が突合検証される旨を明記する。

## Acceptance Criteria
- [ ] `AGENTS.md` と `regista-gm/SKILL.md` で handover 保存先パスの表記が `.regista/handover/` で一致していること。
- [ ] `regista-gm/SKILL.md` の retry 指示フォーマットに `"bypass_cache": true` が明記されていること。

## Verification Commands
```bash
rtk grep -i "handoffs" AGENTS.md .agents/skills/regista-gm/SKILL.md
```
