# 🎯 L2-3D-002: オブジェクトドラッグ（ポインタディスパッチャ・ボール・選択枠）のUnproject統一

## UX Impact
チルト状態で選手・ボール・矢印等のオブジェクトをドラッグすると、ポインタとオブジェクトが離れていく「滑走現象」が解消される。いかなるチルト角・ズームでもオブジェクトがカーソルに追従する直感的な操作感になる。

## Detailed Spec

### 前提
- `L1-3D-001` が完了し、`unprojectScreenToPitch`, `buildMVPMatrix` が利用可能なこと
- Scout調査によると以下のファイルがドラッグ座標変換の責務を持つ：
  - `use-canvas-pointer-dispatcher.ts` — Konvaステージのポインタイベントを各オブジェクトにディスパッチ
  - `use-canvas-pointer-interaction.ts` — インタラクション状態管理（選択・ドラッグモード切替）
  - `use-ball-drag.ts` — ボール専用ドラッグフック

### 1. useCanvasPointerDispatcher の改修
`use-canvas-pointer-dispatcher.ts`

**現在の問題**: KonvaのPointerEventから取得した `stage.getPointerPosition()` を `stageToPitch` や `screenToPitch` に通しているが、チルト時に歪む。

**改修方針**:
1. `stage.getPointerPosition()` で取得した**ステージ座標（Konva内部座標）**を `unprojectScreenToPitch` で逆変換するには、**クライアント座標（clientX/Y）**を使う必要がある。Konvaイベントの `evt.clientX, evt.clientY` を活用する。
2. `useCanvasPointerDispatcher` が各コールバックに渡す座標オブジェクトのシグネチャを `NormPoint`（`matrix-coordinates.ts`の型）に統一する。
3. 既存の `getStagePitchAndNormPos` / `getPitchAndNormPos` の呼び出しを `unprojectScreenToPitch` に置き換える。

```ts
// 変更前
const { normPos, pitchPos } = getStagePitchAndNormPos(stage, pitchTransform)

// 変更後
const normPos = unprojectScreenToPitch(
  { x: evt.clientX, y: evt.clientY },
  cameraParams
)
if (!normPos) return
```

### 2. useCanvasPointerInteraction の改修
`use-canvas-pointer-interaction.ts`

- `pointerdown` でのオブジェクト選択ヒットテストに使う座標をunprojectedなnorm座標に変更する
- ドラッグ開始位置（`dragStartNormRef`等）の記録をunprojectベースに変更する
- 既存のインタラクション状態管理ロジック（選択モード、ドラッグモード切替）は変更しない

### 3. useBallDrag の改修
`use-ball-drag.ts`

- ボールの `pointermove` 時のデルタ計算を `unprojectScreenToPitch` ベースに変更する
- `use-canvas-pointer-dispatcher.ts` から渡ってくる座標がすでにnorm座標に統一されていれば、このフックでの変換は不要になる可能性がある（依存関係を確認してから実装すること）

### 共通ガイドライン
- `cameraParams` は以下から構築する：
  ```ts
  const { pitchTransform } = useTacticalUnifiedStore()
  const cameraParams: CameraParams = {
    tilt: pitchTransform.tilt,
    zoom: pitchTransform.zoom,
    panX: pitchTransform.panX,
    panY: pitchTransform.panY,
    stageWidth,   // Konvaステージの実際のwidth(px)
    stageHeight,  // Konvaステージの実際のheight(px)
  }
  ```
- `unprojectScreenToPitch` が `null` を返した場合（ピッチ外クリック）はイベントを無視する
