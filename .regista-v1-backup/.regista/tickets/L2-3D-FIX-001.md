# 🎯 L2-3D-FIX-001: useCanvasPointerDispatcherおよびBallDragの2D/3Dポインタ整合回復

## UX Impact
2D表示（チルト0度）において、選手やボールの選択・ドラッグ・描画ツール・範囲選択が完全に動作を回復し、3Dチルト時でもポインタが正確に吸着してオブジェクト操作が行えるようになります。

## Detailed Spec

### 1. `use-canvas-pointer-dispatcher.ts` のポインタ判定・2Dフォールバック
- `resolvePointerPositions` において、`tilt === 0` の場合は従来の 2D 変換（`getPitchAndNormPos` / `getStagePitchAndNormPos`）を直接利用、または修正された `matrix-coordinates` を呼び出す。
- `isInsidePitch` 判定で、ピッチ外ドラッグ（選択解除やドラッグ追従）時にイベントが早期破棄されないよう修正。
- `containerRef` 基準の座標オフセットと Konva Stage の `effectivePitch.x / y` の対応関係を整理。

### 2. `use-ball-drag.ts` の座標整合
- ボールドラッグ中およびドラッグ終了時の座標計算が、2D（tilt=0）および 3D（tilt>0）の双方で正確にピッチ座標系（0-100% または実ピクセル）に変換されることを保証。

## Acceptance Criteria
- [ ] 2D（tilt=0）でピッチ上のクリック、ボール・選手のドラッグ、描画ツールが正しく反応する
- [ ] 3D（tilt>0）でもボールのドラッグ追従が動作する
- [ ] `rtk pnpm type-check:scoped` / `rtk biome check` がエラーゼロで通過する

## 📝 Implementation & Write-back Log (Worker記入欄)

### 1. 変更内容サマリー
- `use-canvas-pointer-dispatcher.ts`:
  - `tilt === 0` (2D) 時に従来の `getPitchAndNormPos` による 2D 変換を直接利用するバイパスを実装。
  - 3D 逆射影時に `effectivePitch` の x, y, width, height とステージサイズを正しく渡し、オフセットとアスペクト比の整合性を確保。
  - `isInsidePitch` 判定をピッチ矩形内外判定に修正し、背景（ピッチ外）クリック時の早期 return を撤廃してピッチ外ドラッグ（選択解除・ラバーバンド選択等）が破棄されないよう修正。
  - `resolveStageSize` および `dispatchPointerMoveTarget` を抽出して Cognitive Complexity を解消。
- `use-ball-drag.ts`:
  - `resolveBallUnprojectPos` で `pitchWidth`, `pitchHeight`, `pitchRect` を渡して 3D 逆射影時の横幅狂いを防止。
  - 2D（tilt===0）時は Konva 標準のドラッグ座標系（`node.x()`, `node.y()`）を尊重した位置確定ロジックを維持・回復し、3D（tilt>0）時は `unprojectScreenToPitch` による正確なピッチ吸着・位置確定を行うよう分岐。
  - `updateBallDragMovePosition`, `updateBallGhostLine`, `resolveBallFinalNormPos` を抽出して関数の行数制限（100行以内）をクリア。
