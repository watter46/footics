# 🏟️ L3-3D-003: エクスポート描画エンジンにおける背景ピッチおよびゾーンの3D射影・向き同期対応

## UX Impact
エクスポートプレビューおよび動画エクスポート時に、選手だけでなく背景のピッチライン（外枠・ペナルティエリア・センターサークル等）やゾーンもキャンバスのチルト・ズーム・パン・アスペクト比（16:9, 9:16, 4:5, 1:1）と完全に同期して3Dパースペクティブ描画されるようになる

## Detailed Spec
1. `src/lib/tactical/export/tactical-frame-renderer.ts`:
   - `pitch-geometry.ts` の `calculatePitchGeometryForAspect` を用いて、`aspectRatio`（`16:9`, `9:16`, `4:5`, `1:1`）に応じた正確なピッチ座標・向き設定（`orientation`）を取得する
   - `mvpMatrix` が存在する場合に、ピッチ背景・外枠タッチライン・ハーフウェイライン・センターサークル・ペナルティエリア・ゴールエリア・ペナルティ弧・コーナーアーク・スポットを描画する 3D 射影描画ヘルパーを実装:
     - `toNormX` / `toNormY`: ピッチ幾何座標（px）から正規化座標 (0..100) への変換
     - `projectPitch`: `projectObjToScreen(toNormX(vx), toNormY(vy))` によるスクリーン座標計算
     - `draw3DQuad`: 4頂点を `projectPitch` で射影し `beginPath -> moveTo -> lineTo x 3 -> closePath -> fill / stroke`
     - `draw3DLine`: 2頂点を `projectPitch` で射影してライン描画
     - `draw3DArc`: 円弧（センターサークル、ペナルティ弧、コーナーアーク等）を複数点（例: 32〜64分割）サンプリングして `projectPitch` で射影し `lineTo` で結ぶ
     - `draw3DSpot`: スポットの描画
   - `mvpMatrix` が存在しない場合は従来の 2D 平面描画にフォールバック（既存互換性を維持）
   - ゾーン（`frame.zones`）の描画処理でも、各頂点座標を `projectObjToScreen` で射影して描画する
2. `src/lib/tactical/export/__tests__/tactical-frame-renderer.test.ts`:
   - `mvpMatrix` 指定時に 3D 射影ピッチ描画パスが実行されることを検証するテストケースを追加
   - 各アスペクト比（16:9, 9:16, 4:5, 1:1）でピッチとゾーンが正しく描画処理を通過することを検証
