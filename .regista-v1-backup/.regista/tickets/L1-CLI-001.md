# 📋 L1-CLI-001: エージェント出力テンプレートとCLI一覧表示スクリプトの新フォーマット対応

## UX Impact
モニター分割時の狭小幅ペイン（WezTerm等）でもチケット一覧の表示が崩れず、Ticket IDが改行されずに単独行として配置されることで、ダブルクリックやドラッグによるTicket IDの一発コピーが確実に行えるようになる。

## Detailed Spec
1. `.regista/templates/board-summary.md` を更新し、4項目縦積みカード型フォーマット（`[🔴 Ticket ID]`、`[タスク名]`、`[推奨モデル / Effort]`、`[実装後]`）を定義する。
2. `.agents/scripts/list-tickets.js` を更新し、チケット各ファイルから YAMLフロントマター（`id`, `title`, `model`, `effort`）および本文の `## UX Impact` を抽出し、新フォーマットに沿って出力するように実装する。
3. レイヤー番号に応じた絵文字（L1: 🔴, L2: 🟡, L3: 🟢, etc.）を各チケットの `[絵文字 Ticket ID]` ラベルに反映する。

## Acceptance Criteria
- [ ] `.regista/templates/board-summary.md` が新しい縦積みカード型フォーマットになっていること
- [ ] `pnpm tickets` を実行した際に、チケットが `[🔴 Ticket ID]` 直下にID、`[タスク名]`、`[推奨モデル / Effort]`、`[実装後]` の順で綺麗に出力されること
- [ ] 画面幅が狭くても Ticket ID が独立して行頭に表示され、ダブルクリック等で確実に選択できること

## Verification Commands
```bash
rtk pnpm tickets:validate
rtk pnpm tickets
```
