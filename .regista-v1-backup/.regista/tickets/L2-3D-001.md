# 🎮 L2-3D-001: Pan/Zoomフック（useCanvasPitchPan/useCanvasWheelZoom/useCanvasZoomPan）のUnproject統一

## UX Impact
チルト時にピッチを掴んで移動（Pan）すると、マウスポインタと掴み地点が徐々に離れていく「滑走現象」が解消される。どのチルト角・ズーム倍率でもクリック地点がカーソルに常に吸着する直感的な操作感になる。

## Detailed Spec

### 前提
- `L1-3D-001` が完了し、`matrix-coordinates.ts` が `src/features/tactical-unified/objects/canvas/helpers/index.ts` からexportされていること
- Scout調査によると、現在チルトはHTMLラッパーのCSS 3D（perspective: 1200px + rotateX）で実現されており、Konva内部は2D Zoom/Panのみ保持。座標変換の誤差源はここにある。

### 1. useCanvasPitchPan の改修
`use-canvas-pitch-pan.ts`

**現在の問題**: `screenToPitch` または手動計算によりPointerDown/MoveのΔを計算しているが、チルト時に歪む。

**改修方針**:
1. `pointerdown` 時に `unprojectScreenToPitch({ x: e.clientX, y: e.clientY }, cameraParams)` でピッチ座標を取得し `grabNormRef` に保存する
2. `pointermove` 時に現在のポインタ位置を同様にunprojectし、`grabNormRef` との差分をpan deltaとして `useTacticalUnifiedStore` の `setPitchTransform` に適用する
3. `cameraParams` は `pitchTransform` + `stageWidth/Height` から構築する（`buildMVPMatrix` 用）

```ts
// 変更前（概念コード）
const delta = screenToPitch(current) - screenToPitch(prev)

// 変更後
const grabNorm = unprojectScreenToPitch({ x: e.clientX, y: e.clientY }, cameraParams)
if (!grabNorm) return
const delta = { x: grabNorm.x - grabNormRef.current.x, y: grabNorm.y - grabNormRef.current.y }
store.setPanOffset(delta)
```

### 2. useCanvasWheelZoom の改修
`use-canvas-wheel-zoom.ts`

**現在の問題**: ホイールズーム時のフォーカス点（カーソル下のピッチ座標）計算が2D前提。

**改修方針**:
1. `wheel` イベント時にカーソル位置を `unprojectScreenToPitch` でピッチ座標に変換する
2. 新ズーム倍率でのProjection後のピッチ座標と元座標の差分でpanを補正し、カーソル中心ズームを実現する
3. ズーム倍率は既存の `deltaY` ベース計算を維持し、pan補正のみ変更する

### 3. useCanvasZoomPan の改修
`use-canvas-zoom-pan.ts`

- pinch zoom（タッチデバイス）でも同様のunproject-based中心点補正を適用する
- 既存の2点タッチ中心座標計算部分を `unprojectScreenToPitch` ベースに変更する

### CameraParams の組み立て方（共通）
```ts
import { buildMVPMatrix, unprojectScreenToPitch } from '../helpers/matrix-coordinates'
import type { CameraParams } from '../helpers/matrix-coordinates'

const cameraParams: CameraParams = {
  tilt: pitchTransform.tilt,
  zoom: pitchTransform.zoom,
  panX: pitchTransform.panX,
  panY: pitchTransform.panY,
  stageWidth,
  stageHeight,
}
```
