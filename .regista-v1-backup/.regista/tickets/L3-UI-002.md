# 🟠 L3-UI-002: 境界線トグルUI調整とエクスポートフックへの統合

## UX Impact
ユーザーがツールバーから境界線表示をトグルした際のみ境界線が表示され、画像/動画のエクスポートパイプラインが非表示状態でも正しくAutoFitで書き出せるようUI/Hooksが統合されます。

## Detailed Spec
1. `drawing-toolbar.tsx` および `boundary-box-hud.tsx` のトグルUIを修正し、ONにした時に `visible: true` に切り替え、かつ現在のピッチ位置へラップ（AutoFit初期設定）するように修正する。
2. `use-konva-export.ts` および `use-konva-video-export.ts` フック内でエクスポート処理を発火させる際、`konva-export-helpers` にピッチ位置等の必要情報を正しく渡し、動的AutoFit算出が確実に動作するように繋ぎ込みを行う。
3. `unified-canvas.tsx` 内の依存関係とフック呼び出しの調整。

## Acceptance Criteria
- [ ] ツールバーのトグルUIで境界線の表示/非表示が正しく切り替わること。
- [ ] エクスポートのHooksがピッチ位置情報をヘルパーに適切に渡し、静止画・動画エクスポートが動作すること。

## 📝 Implementation & Write-back Log (Worker記入欄)

### 1. 変更内容サマリー
- `drawing-toolbar.tsx`: 境界線（Crop枠）トグルボタンを追加。ON切替時に `autoFitBoundaryBox` を呼び出して現在ピッチ位置へラップし `visible: true` に更新、OFF切替時に `visible: false` に更新。
- `boundary-box-hud.tsx`: `visible: false` 時はHUDを非表示化。アスペクト比プリセット適用時やAutoFitPitch/AutoFitCanvas時に `visible: true` を付与。
- `unified-canvas.tsx`: `transformedPitchRect` (ピッチのpan/zoom/tiltを反映した現在矩形) を算出し、`BoundaryBox` および `BoundaryBoxHud` / `ContextHud` に渡すことでピッチ移動・ズーム時の境界線のズレを完全解消。
- `use-konva-export.ts`: `calculateExportCropRect` の呼び出し時にスライドの `pitchTransform` を渡し、動的AutoFitクロップ座標計算を統合。
- `use-konva-video-export.ts`: 動画エクスポート時の型安全な引数検証・オプション抽出ヘルパーへの分離と、BoundaryBox連携の整理。
