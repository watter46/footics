# 📊 L1-OBS-001: ログパーサーおよびメトリクス永続化スクリプトの実装

## UX Impact
開発者やGMがセッション終了時にトークン消費量をコンソールで即座に確認できるようになり、長期的なコスト推移も可視化される。

## Detailed Spec
1. **パーサーの実装 (`scripts/metrics/collect-tokens.js`)**:
   - 外部依存のないNode.jsの標準モジュール（`fs`, `readline`等）を使用すること。
   - 標準入力（stdin）からJSON形式で `transcriptPath` などのメタデータを受け取る。
   - 該当の `transcript_full.jsonl` を読み込み、以下の情報をヒューリスティックに算出する。
     - GM Input Tokens (目安: ユーザー/システム入力の文字数 / 4)
     - GM Output Tokens (目安: モデル出力の文字数 / 4)
     - ツール呼出ターン数 (`PLANNER_RESPONSE` の `tool_calls` 数)
     - 全エージェント総トークン数
2. **永続化層の実装**:
   - 算出したメトリクスをタイムスタンプ等のメタデータと共に `.agy/metrics/token_usage.jsonl` に追記保存する。
3. **フック仕様の準拠**:
   - AntigravityのHook仕様に準拠するため、標準出力（stdout）には必ず `{"decision": "continue"}` または `{}` を出力し、実行ループを阻害しないこと。
   - サマリーなどのログは `console.error` を用いて出力すること。

## Acceptance Criteria & Verification Commands
- [ ] `scripts/metrics/collect-tokens.js` が実装され、単体で動作する。
- [ ] 標準入力から `transcriptPath` を渡し、`.agy/metrics/token_usage.jsonl` に正しい形式で追記される。
- [ ] 標準出力には正しいフックの戻り値（JSON）が出力され、サマリーがエラー出力に出力される。
