# 🟢 L1-CLI-002: make done の日本語化・クワイエット化および旧チケット警告の非表示

## UX Impact
`make done` 実行時にバリデーション途中ログや旧チケットに対するAAWU等の警告（Warnings/Alerts）が表示されず、正常完了時は日本語1行（`✅ 完了: <ID> (コミット: <hash>)`）のみが出力されるようになります。

## Detailed Spec
1. `.agents/scripts/validate-tickets.js`:
   - `--quiet` または `-q` オプションのサポートを追加し、指定時は正常時のログ（`🔍 [Regista Ticket Validator]`, `Validated X tickets...`, `✅ All tickets passed...`）および過去チケットに対する AAWU 等の Warning（警告）を出力しないようにする（エラー発生時のみ標準エラーに出力して exit 1）。
2. `.regista/scripts/ticket-done.ts`:
   - `runValidation` の実行時に `--quiet` を付与し、正常時は `Validating tickets...` などの途中メッセージを出さないようにする。
   - 正常完了時のメッセージを日本語化: `✅ 完了: ${idsList} (コミット: ${commitHash})`
   - エラー時・警告時のメッセージを日本語化。
   - 不要な中間ログをクワイエット化し、成功時は1行のみを出力するようにする。

## Acceptance Criteria
- [ ] `make done` 実行時にバリデーション中のログや過去チケットの AAWU 警告一覧が表示されない
- [ ] 正常完了時に `✅ 完了: <ID> (コミット: <hash>)` と日本語1行のみが出力される
- [ ] エラー発生時は分かりやすい日本語でエラー内容が出力され、正常に失敗する

## Verification Commands
```bash
pnpm type-check:scoped .regista/scripts/ticket-done.ts
rtk biome check .regista/scripts/ticket-done.ts
node .agents/scripts/validate-tickets.js --quiet
```
