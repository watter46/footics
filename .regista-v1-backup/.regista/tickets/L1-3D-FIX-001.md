# 📐 L1-3D-FIX-001: matrix-coordinates.tsの2Dバイパスおよびピッチ矩形/アスペクト比/Pan(px)整合化

## UX Impact
`matrix-coordinates.ts` において、`tilt === 0` の場合は従来の確実な 2D 平行投影・アフィン変換へと直接バイパスし、また長方形ピッチのアスペクト比や px 単位の PanX/PanY が正しく処理されるようになります。これにより、2D ピッチ表示時に座標逆変換（`unprojectScreenToPitch`）が不正に `null` を返して操作不能になる根本原因が解消されます。

## Detailed Spec

### 1. `tilt === 0` 時の 2D バイパス
- `unprojectScreenToPitch` および `projectPitchToScreen` において、`params.tilt === 0`（または未指定）の場合は 3D 透視投影（FOV 60度）を介さず、ピッチ矩形と Zoom / Pan (px) による高精度な 2D 線形変換を行う。

### 2. アスペクト比・ピッチ矩形寸法の反映
- `CameraParams` にピッチ矩形の幅・高さ（およびオフセット）が渡された際、正方形 1x1 固定ではなくアスペクト比を反映したモデル変換行列を構築する。
- `normPoint` の 0〜1 範囲外（ピッチ外領域）であっても、ドラッグや選択操作を継続できるように `clamp` または外挿座標を返し、無闇に `null` を返却しない設計にする。

### 3. PanX / PanY の px 単位系整合
- ストアが保持する px 値（例: 50px）を正規化座標系と誤認して画面外へモデルが吹き飛ぶ現象を防ぎ、Stage ピクセル空間でのオフセットとして正しく MVP 行列に組み込む。

### 4. 単体テストの拡充
- `matrix-coordinates.test.ts` に `tilt = 0` の 2D 完全互換テスト（正変換・逆変換の一致）および長方形ピッチのテストケースを追加。

## Acceptance Criteria

- [x] 16:9 などの長方形ピッチでピッチ境界付近や外側をクリックしても不正な `null` 落ちが発生しない
