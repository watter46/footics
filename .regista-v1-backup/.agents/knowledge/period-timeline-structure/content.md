# ピリオドとタイムライン構造 (Period & Timeline Structure)

## 概要
サッカーの試合時間を管理するための「ピリオド (Period)」の制約、時間バリデーション、およびタイムライン上でのソートに関するドメイン知識の定義です。

## 厳守すべき制約 (Constraints)

1. **時間のパースとピリオドの定義**
   - イベントは `period`, `minute`, `second` の3つで管理されます。
   - `period` の定義: `1` (前半), `2` (後半), `3` (延長前半), `4` (延長後半), `5` (PK戦)。
   - **分 (minute) は絶対時間（経過時間）** で記録されます。つまり後半の開始は「45分」、延長前半の開始は「90分」となります。

2. **時間の入力バリデーション**
   - 各ピリオドには、入力可能な「最小時間 (`MIN_MINUTES_PER_PERIOD`)」が存在します。
     - 第2ピリオド (後半) は **45分以降**。
     - 第3ピリオド (延長前半) は **90分以降**。
     - 第4ピリオド (延長後半) は **105分以降**。
   - `src/lib/features/MemoOverlay/memoOverlayLogic.ts` 等での時間パース時（`getValidationError`）に、この制約に違反する場合はエラーを返してください。

3. **表示時のパース処理 (`PERIOD_LIMITS`)**
   - 各ピリオドの基本制限時間 (`PERIOD_LIMITS`) を超えた場合、表示はアディショナルタイム（例: `45 + 2:30`）としてフォーマットされます。
     - 制限: 1=45, 2=90, 3=105, 4=120。
   - イベントをレンダリングする UI コンポーネントは、単純に `minute:second` を表示するのではなく、必ず `parseTimeStr` 等の共通ヘルパーを介してアディショナルタイムを計算してください。

4. **ショートカットの実装方針**
   - ピリオドの切り替え（PhaseTimeInput等）には、`Alt+1` 〜 `Alt+5` のショートカットがバインドされています。
   - インプット要素でイベントをキャプチャする際、数字キー（時間入力）のイベント伝播は止めつつ、`Alt` や `Ctrl` 等の修飾キーを含むショートカット操作は**バブリングさせて上位のグローバルハンドラに渡す**ように制御してください。
