# 🟩 L3-3D-004: エクスポート描画エンジンにおける境界線（BoundaryBox）領域のキャンバス・ビューポート変換（Viewport Transform）一括フィット拡大対応

## UX Impact
プレビュー（ExportPreviewPlayer）およびエクスポート動画において、2D/3Dに関わらずユーザーが指定した境界線（BoundaryBox）の矩形枠内の映像が、プレビュー画面・出力キャンバス全体に歪みなく自然に拡大フィット（Crop & Zoom）して表示されるようになる。

## Detailed Spec
1. `src/lib/tactical/export/tactical-frame-renderer.ts`:
   - 個別描画関数（`toScreenX/toScreenY` や `rawProject3D`）内部に分散していた BoundaryBox のオフセット・スケール計算、および 3D MVP 行列に BoundaryBox を通して歪んだバウンディングボックスを計算するロジックを **全廃** する。
   - ピッチ幾何・白線・ゾーン・選手・ボール・矢印・テキストの座標計算は、常に **キャンバス基準の素のスクリーン座標（0..width, 0..height）** を出力するように統一する。
   - **一括ビューポート変換（Global Viewport Transform）の適用**:
     - 描画の最上流（背景描画直前）で Canvas コンテキストに対して `ctx.save()` を実行。
     - `isBoundaryActive`（`boundaryBox` 指定時）の場合:
       - 画面上のクロップ矩形（ピクセル値）を計算:
         `cropX_px = (boundaryBox.x / 100) * width`
         `cropY_px = (boundaryBox.y / 100) * height`
         `cropW_px = (boundaryBox.width / 100) * width`
         `cropH_px = (boundaryBox.height / 100) * height`
       - スケール係数 `scaleX = width / cropW_px`、`scaleY = height / cropH_px` を計算。
       - キャンバスコンテキストに `ctx.scale(scaleX, scaleY)` および `ctx.translate(-cropX_px, -cropY_px)` を適用。
       - これにより、2D/3Dの描画ロジックに一切依存せず、境界線枠内の全映像（ピッチ・選手・ボール・テキスト等）がキャンバス全体 `(0, 0, width, height)` に自動的にフィット拡大される。
     - 描画の最末尾で `ctx.restore()` を呼び出してコンテキストを復元する。
2. `src/lib/tactical/export/__tests__/tactical-frame-renderer.test.ts`:
   - BoundaryBox 指定時に、2D および 3D モード双方で `ctx.scale` と `ctx.translate` によるビューポート変換が正しく呼び出され、枠内領域がキャンバス全体にフィットすることを確認する単体テストを追加・更新。
