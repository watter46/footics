# 🪝 L2-OBS-001: セッション終了時フックの登録と動作確認

## UX Impact
エージェントのセッションが終了するたびに、何も操作しなくても自動的にトークン使用量が記録され、サマリーが表示されるようになる。

## Detailed Spec
1. **フックの登録 (`.agents/hooks.json`)**:
   - `hooks.json` に `Stop` フックを定義し、L1-OBS-001 で実装した `scripts/metrics/collect-tokens.js` を実行する設定を追加する。
   - 実行コマンドは `node ./scripts/metrics/collect-tokens.js` 等、パスを正しく設定すること。
2. **動作確認（スモークテスト）**:
   - `agy`（または適切な実行コマンド）で空振り・最小限のセッションを実行し、終了時にフックが発火することを確認する。
   - コンソールにサマリーが表示され、`.agy/metrics/token_usage.jsonl` にデータが追記されることを一連のフローとして確認する。

## Acceptance Criteria & Verification Commands
- [x] `.agents/hooks.json` に `Stop` イベントのフックが正しく定義されている。
- [x] 実際のセッション終了時にスクリプトが自動実行され、メトリクスが記録される。
- [x] コンソールにサマリーログが表示され、後続のプロセスのブロック（ハング）が発生しない。

### Verification
- 任意のエージェントセッションを起動・終了し、ログ出力を確認する。
