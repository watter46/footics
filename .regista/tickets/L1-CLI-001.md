# 🟢 L1-CLI-001: make done の並列作業対応（Diff Gate スコープ限定化）

## UX Impact
別チケットや別チャットでWorkerが並列作業中であっても、対象チケットの `make done` がブロックされず確実に完了・個別コミットできるようになる。

## Detailed Spec
1. `.regista/scripts/ticket-done.ts` の `validateDiffGate` 関数および関連検証ロジックを改修する。
2. `git status` の変更一覧のうち、対象チケットに含まれていないファイル（他チケット作業中ファイル）が存在しても、エラー中断（`process.exit(1)`）させず、警告（`console.warn` で「スキップした他変更ファイル」として表示）にとどめて処理を継続する。
3. 一方で、対象チケットの Write-back（変更ファイル一覧）に記載されたファイルが、実際に作業ツリー上で変更または存在しているかの検証は維持し、チケット関連ファイルのみを確実に `git add` してコミットする。

## Acceptance Criteria
- [ ] 他の無関係なファイルが作業ツリー上で変更されていても、指定チケットの `make done` がエラー終了せずコミットに成功すること。
- [ ] 指定チケットに記載されたファイルのみがステージング・コミット対象となること。
- [ ] `rtk pnpm tickets:validate` をパスすること。

## Verification Commands
```bash
rtk pnpm tickets:validate
rtk biome check .regista/scripts/ticket-done.ts
```
