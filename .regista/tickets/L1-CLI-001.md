# 🔧 L1-CLI-001: ticket-done.ts CLIスクリプト新規作成

## UX Impact
`make done L1-UI-001` または `make done L1-UI-001 L1-UI-002` で複数チケットを一括でDONEにしてgit commitできるCLIツールが使えるようになる

## Detailed Spec
1. `tsx .regista/scripts/ticket-done.ts <ID...>` で起動する（複数ID可）。例: `ticket-done.ts L1-UI-001 L1-UI-002`
2. 渡されたすべてのチケットIDに対し、`.regista/tickets/[ID].md` を読み込みYAMLフロントマターの `status` を `DONE` に書き換える
3. `node .agents/scripts/validate-tickets.js` を子プロセス（`execSync`等）で実行し、バリデーションがPASSすることを確認する（FAILの場合はエラーを出力して終了）
4. 単一チケットの場合: `feat(tickets): done L1-UI-001 - {チケットタイトル}` 形式のコミットメッセージを自動生成
5. 複数チケットの場合: `feat(tickets): done L1-UI-001, L1-UI-002 ({件数} tickets)` 形式のコミットメッセージを自動生成
6. `git add .regista/tickets/*.md && git commit -m '{message}'` を実行する（`execSync`使用）
7. エラー時は分かりやすいメッセージを出力してprocess.exit(1)する
8. 成功時は `✅ Done: {IDs} committed as {hash}` を出力する
9. TypeScript: `import`は `node:fs`, `node:path`, `node:child_process` のみ使用（外部ライブラリ不要）。スクリプトファイルは `.regista/scripts/ticket-done.ts` として作成し、`tsx` で実行する
10. YAMLフロントマターのパースは正規表現で簡易実装する（`.agents/scripts/validate-tickets.js` の実装を参考に）
11. `.regista/scripts/` ディレクトリは未作成のため、スクリプト保存前にディレクトリを作成すること（`mkdir -p .regista/scripts`）
