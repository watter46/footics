# 🎮 L2-3D-FIX-002: useCanvasPitchPanおよびuseCanvasWheelZoomの2D/3D Pan計算安定化

## UX Impact
2D（tilt=0）および3Dチルトの双方で、スペースキー/中ボタンドラッグによるピッチ移動（Pan）やホイールズームがカーソル位置を中心として自然かつ正確に動作します。

## Detailed Spec

### 1. `use-canvas-pitch-pan.ts` の Pan 計算
- `tilt === 0` の場合はシンプルな 2D px 差分（`deltaX`, `deltaY`）で Pan を加算するバイパスを確保。
- 3D チルト時も、修正された `unprojectScreenToPitch` を用いてカーソル吸着を維持。

### 2. `use-canvas-wheel-zoom.ts` のカーソル中心ズーム
- `tilt === 0` 時にズーム中心点のずれが発生しないよう、2D / 3D 両対応のズームオフセット補正を行う。

## Acceptance Criteria
- [x] 2D（tilt=0）でホイールズームとピッチパンが滑らかに動作する
- [x] 3D（tilt>0）でもカーソル中心ズーム・パンが動作する
- [x] `rtk pnpm type-check:scoped` / `rtk biome check` がエラーゼロで通過する
