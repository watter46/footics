# 🎥 L3-3D-001A: Worker通信インターフェース定義とFrameRenderer透視投影描画対応

## UX Impact
エクスポート動画のWorker描画においてMVP行列を利用した正確な3D透視投影が可能になる

## Detailed Spec
1. `video-export-worker.ts` にある `VideoExportWorkerRequest` 型に `mvpMatrix?: Float32Array | null;` を追加する
2. `tactical-frame-renderer.ts` にある `RenderTacticalFrameOptions` 型に `mvpMatrix?: Float32Array | null;` を追加する
3. Workerの受信ループ、および `tactical-frame-renderer.ts` の描画処理において、受け取った `mvpMatrix` を `projectPitchToScreen` に渡すための対応を行う

## Acceptance Criteria
- [x] `VideoExportWorkerRequest` と `RenderTacticalFrameOptions` に `mvpMatrix` が追加されている
- [x] `tactical-frame-renderer.ts` で `mvpMatrix` を利用して3D投影が適用されている
