# ⚙️ L1-CLI-002: Makefile・package.jsonへdoneコマンド登録

## UX Impact
`make done L1-UI-001` および `pnpm ticket:done L1-UI-001` コマンドが使えるようになる

## Detailed Spec
1. `package.json` の scripts に `"ticket:done": "tsx .regista/scripts/ticket-done.ts"` を追加する（既存の `tickets:validate` スクリプトの隣に配置）
2. `Makefile` に `done` ターゲットを追加する。形式:
   ```makefile
   done: ## チケットをDONEにしてコミット (例: make done L1-UI-001 L1-UI-002)
   	pnpm ticket:done $(filter-out $@,$(MAKECMDGOALS))
   
   %:
   	@:
   ```
3. Makefileに `%:` ターゲット（引数受け取り用のno-opルール）が未定義の場合は追加する: ファイル末尾に追加
4. Makefileの `help` ターゲットの出力に `done` が自動的に表示されるよう、## コメントを付与する（既存のhelpターゲットの形式に準拠）
