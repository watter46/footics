# 🎦 L3-3D-002: エクスポートプレビューおよび動画エクスポートへのMVP行列・アスペクト比伝達対応

## UX Impact
エクスポートプレビュー画面でキャンバスと同じチルト・ズーム・パン設定が反映され、4種のアスペクト比（16:9, 9:16, 4:5, 1:1）で歪みなく正確に確認・エクスポートできるようになる

## Detailed Spec
1. `export-preview-player.tsx`:
   - `ExportPreviewPlayerProps` に `pitchTransform?: TacticalPitchTransformState` を追加
   - アスペクト比に応じたプレビュー用キャンバス解像度（`16:9` -> 640x360, `9:16` -> 360x640, `4:5` -> 360x450, `1:1` -> 360x360）の算出ロジックを実装
   - `buildExportMVPMatrix` を用いて、プレビュー用キャンバスサイズ（width, height）と `pitchTransform`、`aspectRatio` から `mvpMatrix` を算出して `renderTacticalFrameToCanvas` の options に渡す
2. `export-modal-body.tsx`:
   - `ExportModalBody` から `ExportPreviewPlayer` に `pitchTransform={activeSlide?.pitchTransform}` を渡す
3. `use-konva-video-export.ts`:
   - `exportTacticalVideo` を呼び出す際の引数オブジェクトに `pitchTransform: activeSlide?.pitchTransform` を追加し、エクスポート実行時にもカメラ設定が確実に反映されるようにする

## Acceptance Criteria
- [x] `ExportPreviewPlayer` に `pitchTransform` が渡され、`buildExportMVPMatrix` で生成された `mvpMatrix` が `renderTacticalFrameToCanvas` に渡されている
- [x] `ExportPreviewPlayer` で `16:9`, `9:16`, `4:5`, `1:1` の各アスペクト比に応じた適切なキャンバスサイズが設定されている
- [x] `use-konva-video-export.ts` から `exportTacticalVideo` に `pitchTransform` が渡されている
- [x] `rtk pnpm type-check:scoped` および `rtk biome check` がパスする
