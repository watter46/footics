# Video Canvas Konva Migration & Tactical Object Specifications

## 1. 概要
`video-canvas`（Chrome拡張機能）における描画エンジンを、従来の `tldraw` から `react-konva` へ完全に移行しました。
`src/components/features/TacticalBoard/` とアーキテクチャおよび操作感を統一しつつ、動画スクリーンショット分析特化の高度な機能（選手マーカー、視野角FOV、マンマーク、厳密な中心間直線コネクタ、0msリアルタイム追従、多角形ゾーン、自由トリミング枠）を自前実装しています。

## 2. 実装された戦術オブジェクト一覧と仕様

| オブジェクト | 内部種別 | ショートカット | 仕様詳細 |
|---|---|---|---|
| **選択ツール** | `select` | `V` / `1` | シェイプの選択、移動、変形（Transformer）、リサイズ |
| **実線矢印** | `arrow_solid` | `A` / `2` | 実線矢印。端点ハンドルによる伸縮・回転、Bezier制御点によるカーブ変形 |
| **点線矢印** | `arrow_dash` | `D` / `3` | 点線矢印（`dash: [16, 14]`）。実線と同じ操作性 |
| **ゾーン** | `zone_circle` | `Z` / `4` | 矩形（SQUARE）/ 楕円（CIRCLE）をスタイルパネルで切替。四隅外側ホバーで回転 |
| **多角形ゾーン** | `polygon_zone` | `P` / `5` | クリックで頂点を打っていき、始点近傍クリックまたは Enter / ダブルクリックで閉じる。各頂点ハンドルで自由変形 |
| **選手マーカー** | `marker` | `M` / `6` | 3Dパース付き足元リング（5つのSVG円弧＋中心コア）、電球アイコンでスポットライト（光柱）ON/OFF |
| **消しゴム** | `eraser` | `E` / `7` | クリックしたオブジェクト（およびマーカー従属の子オブジェクト）を即座に削除 |

## 3. 選手マーカーの従属オブジェクトと幾何学エンジン

1. **0ms リアルタイム追従（`handleMarkerDragMove`）**
   - マーカーをドラッグしている最中（`onDragMove`）、従属する子ノード（矢印、FOV、マンマーク、コネクタ線）の Konva ノードを直接操作し、1フレームの遅延もなく追従させる。
   - `onDragEnd` で React state `shapes` および Undo 履歴を一括確定。

2. **厳密な Ray-Ellipse Intersection コネクタ計算（`getConnectorPoints`）**
   - マーカーAの中心 $(cx_1, cy_1)$ とマーカーBの中心 $(cx_2, cy_2)$ を結ぶ直線上に、始点・終点が 100% 正確に乗るように計算。
   - $t = \frac{r_x r_y}{\sqrt{(r_y u_x)^2 + (r_x u_y)^2}}$ により、外周上の真の交点から交点へ直結。線を延長すると両マーカーの中心を完全に貫通する。

3. **外周回転型 従属矢印（`getArrowLayout`）**
   - マーカーから生える矢印は、終点ハンドルをドラッグした角度に応じて始点がマーカー楕円リングの外周上を自然に公転。

## 4. スクリーンショット・エディタのレイアウト仕様
- **セーフエリアパディング**: ヘッダー（高さ56px）と下部ツールバー（高さ約70px）に画像や角ハンドルが潜り込まないよう、`PADDING_TOP = 68px`, `PADDING_BOTTOM = 76px`, `PADDING_HORIZONTAL = 32px` でビューポートの `fitScale` を算出。
- **自由トリミング枠**: `captureFrame` の四隅ハンドルをドラッグしてクリッピング領域を自由に変更可能。コピー／保存時にその境界領域のみを高解像度出力。
- **即時複製**: `Ctrl+D`（`Cmd+D`）で選択中のオブジェクトを即座にオフセット複製。
