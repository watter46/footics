# react-konva 開発ガイドライン

本プロジェクト（video-canvas等）における `react-konva` の開発・実装ガイドラインです。パフォーマンス、カスタムシェイプの実装、UI/UXのカスタマイズに関するベストプラクティスを定めます。

## 1. 状態管理 (State Management)
- **Zustandベースの単方向データフロー**: Konvaのノードが持つ内部状態（座標やスケールなど）は、ドラッグ中などの過渡的な状態を除き、必ずZustandストアに同期させてください。
- **ドラッグとパフォーマンス**: ドラッグ中（`onDragMove`）はReactの再描画を避けるため、ノード自体のプロパティで一時的に表示を更新し、ドラッグ終了時（`onDragEnd`）にZustandストアに最終状態を書き戻す手法を推奨します。

## 2. コンポーネント構成 (Component Architecture)
- **原則:** キャンバス (Stage/Layer) と UI (Overlay) を明確に分離する。
- **行動指針:**
    - `Canvas`: `react-konva` の `Stage` と `Layer` をラップし、描画要素を管理する。
    - `Overlay`: キャンバスの上に重なる UI（ツールバー、インスペクタ等）。
    - `Shapes`: カスタムの描画要素はコンポーネントとして分割する。

## 3. パフォーマンス最適化 (Performance)
- **Layerの分割**: 静的な背景画像と、頻繁に更新される描画要素（シェイプ、テキスト）は別々の `Layer` に配置し、再描画コストを抑えてください。
- **画像のキャッシュ**: 画像を読み込む際は、無駄なネットワークリクエストを避けるためのキャッシュ戦略を考慮してください。

## 4. アセットとシステム設定
- **Stageのレスポンシブ化**: ウィンドウのリサイズに応じて `Stage` のサイズを動的に更新し、常に親コンテナに追従するように実装してください。
- **高解像度エクスポート**: スクリーンショットやエクスポート時には `pixelRatio` を適切に設定し、Retinaディスプレイ等でも鮮明な画像を出力できるようにします。

## 5. Build & Deployment (ビルドと同期)
- **ビルド・同期実行:** 実装完了時や更新時は `pnpm run build` を実行する（WXT ビルドおよび `sync-extension` による Windows 側への成果物コピーが自動実行されます）。
